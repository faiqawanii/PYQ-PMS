# PYQ-PMS

Previous Year Question Paper Management System (PYQPMS) is a web-based application developed to provide centralized access to previous year question papers for students and administrators. The platform helps users search, view and download question papers efficiently while allowing authorized admins to manage and organize academic resources.

## Overview

This project is designed to reduce the difficulty students face in finding reliable previous year question papers. It organizes papers by course, subject, semester, year and examination type, making academic resources easier to access and manage.

## Features

- User login interface
- Admin and user role selection
- Dashboard for browsing question papers
- Search and filter functionality
- View and download question papers
- Organized storage of academic documents
- Admin-side paper management support
- Responsive web-based interface

## Project Structure

- `login/` - contains login page files
- `interface/` - contains dashboard and interface files
- `logo/` - contains logo and image assets
- `documentation/` - contains SRS, feasibility report, diagrams, SDD and other project documents

## Modules

### User Module
Students can log in, browse available question papers, apply filters and download relevant papers for exam preparation.

### Admin Module
Administrators can manage question papers, maintain organized records and support secure access control for the system.

### Search and Retrieval
The system supports searching and filtering papers using categories such as subject, course, semester and year.

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

The purpose of this project is to create a simple and accessible system for managing previous year question papers in one place. It improves accessibility, supports efficient retrieval of academic resources and helps maintain authenticity through controlled administration.
